1 · Ollama + Gemma (local AI)

  1. Install Ollama for Windows: ollama.com/download. It runs in the system tray.
  2. In Settings → AI type the model tag (for example the Gemma 12B Q4 tag listed on ollama.com) and click Download model. Also download the small fallback model.
  3. Click Run benchmark. The app keeps the model that passes on your PC (12 GB VRAM, 8 GB RAM).
  4. Switch Mode to LIVE.

Tip: close games/browsers with many tabs while AI is working - RAM is 8 GB.

2 · Etsy Open API v3

  1. Open etsy.com/developers/your-apps → Create a new app.
  2. Copy the Keystring and Shared secret into Settings → Connections → Etsy.
  3. Register this redirect URI (callback URL) in the app: {{ redirects.etsy }}
  4. Click Connect and approve the scopes (listings read/write, shop read, transactions read).
  5. Click Test. New apps start with personal access; that is enough for your own shop.

3 · Pinterest API v5

  1. Business account → developers.pinterest.com/apps → Connect app.
  2. Add redirect URI: {{ redirects.pinterest }}
  3. Save App ID + secret in Settings. While you have Trial access, tick "use sandbox" (pins go to the sandbox). Request Standard access for real publishing.
  4. Connect, then choose a board in Settings → Social.

4 · YouTube Data API v3

  1. Google Cloud Console → new project → enable YouTube Data API v3.
  2. OAuth consent screen: External, add yourself as test user, scopes youtube.upload + youtube.readonly.
  3. Credentials → OAuth client ID → type Desktop app. Copy client ID + secret into Settings. (Desktop clients accept the local redirect {{ redirects.youtube }}.)
  4. Connect. Note: until Google audits your app, uploaded videos are locked to private - the app warns you when that happens.

5 · Instagram & Facebook

Marked unavailable. They need Meta App Review (business verification + permissions such as content publishing). When approved, these platforms can be enabled in a later version.

6 · Weekly routine (2 minutes)

  • Approve listings in the Approval Center.
  • Paste Shop Stats (visits, traffic sources, search terms) in Analytics → Import.
  • Import your bank CSV in Accounting → Reconciliation.
